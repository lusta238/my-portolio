# Gabayo Edwin Portfolio

Personal portfolio site for Gabayo Edwin, a UI/UX designer and full-stack developer based in Uganda.

## Run locally

Open `index.html` in a browser, or serve this directory with any static file server.

## Stack

- HTML
- Tailwind CSS (CDN)
- Alpine.js (CDN)

## Contact form

The contact form opens the visitor's email client with the message pre-filled. To collect submissions directly, connect the form to a service such as Formspree or a server-side endpoint.

## Deployment

Before deploying, update the Open Graph URL in `index.html` with the public URL of this site.
